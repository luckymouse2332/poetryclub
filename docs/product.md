# 产品文档：回中诗社

## 产品定位

回中诗社是面向回中三班 2021—2024 级同学的原创诗作与共同记忆线上归档。网站保存同学们写下的诗、打油诗及相关创作背景，并提供稳定、克制的公开阅读体验。

产品服务于一个边界明确的熟人群体，不以扩大用户规模、提高互动频率或形成通用校园社交平台为目标。首页的诗集合照、年级标识和介绍文字共同说明这一身份来源。

## 当前用户与权限

- 游客无需登录即可查看首页、分页诗作列表和公开诗作详情。
- 持有效邀请码的同学可以注册为成员。注册完成后需要显式登录，不自动建立会话。
- 正常成员可以创建草稿、编辑自己的诗作、发布、撤回，以及删除未发布草稿。
- 被禁用成员保留登录与只读访问，可以查看自己的既有诗作和禁用原因，但不能执行写操作。
- 正常管理员可以管理诗作可见性、用户状态与角色、邀请码和审计记录。管理员权限始终由服务端权威状态决定。

## 当前核心流程

### 公开阅读

1. 游客进入首页，看到诗社介绍、诗集合照和最近发布的三篇诗作。
2. 游客进入诗作列表，按首次发布时间倒序分页浏览。
3. 游客打开诗作详情，阅读标题、正文、作者、创作背景和事件日期等公开信息。

只有处于已发布状态、未被管理员隐藏且具有发布时间的诗作能够进入公开页面。草稿、已撤回或已隐藏诗作对公开访问统一不可见。

### 注册与登录

1. 用户在登录页切换到注册表单，填写昵称、邮箱、密码和邀请码。
2. 服务端校验并原子消费邀请码，创建成员账号；无效、过期、停用或用尽的邀请码不会创建账号。
3. 注册完成后，用户使用邮箱和密码登录，并进入安全的站内返回地址。
4. 用户可以查看最小账户信息并主动登出；登出会使当前服务端会话失效。

### 诗作管理

1. 正常成员创建一篇纯文本草稿，可填写标题、正文、创作背景和事件日期。
2. 成员在“我的诗作”中分页查看草稿和已发布诗作，并编辑自己的内容。
3. 草稿发布后进入公开首页、列表和详情；撤回后立即退出公开读取，但保留首次发布时间。
4. 只有未发布草稿可以由作者删除，已发布作品需要先撤回。

正文以纯文本保存和展示，保留换行与空行，不接受未经净化的 HTML。

### 管理治理

1. 管理员可以隐藏或恢复诗作，并记录原因、操作人和时间。隐藏状态独立于作者的草稿或发布状态。
2. 管理员可以禁用或恢复用户、调整成员与管理员角色；系统阻止自我破坏性操作和移除最后一名正常管理员。
3. 管理员可以创建、查看和停用邀请码。邀请码明文只在创建成功时显示一次，数据库仅保存哈希。
4. 管理动作与审计日志在同一事务内写入；审计记录只读，不提供编辑或删除入口。

## 已实现范围

- 邀请码注册、邮箱密码登录、权威服务端会话和幂等登出。
- `member | admin` 最小角色，以及 `active | suspended` 账号状态。
- 诗作草稿、编辑、发布、撤回、草稿删除、公开分页列表和详情。
- `visible | hidden` 诗作治理状态，以及用户、角色、邀请码和审计管理。
- 暖纸色首页、诗集合照、最近诗作索引、响应式导航、隐私政策和使用条款页面。
- 版本化数据库 migration、生产容器部署和宿主机反向代理边界。

准确的里程碑与验收记录见 `docs/tasks/README.md`。

## 当前未实现范围

- 评论、点赞、收藏和通知。
- 私信、实时聊天、关注关系和推荐算法。
- 标签、全文搜索、作品封面、附件、富文本或 Markdown 编辑。
- 班史时间线、人物档案和活动组织功能。
- OAuth、邮箱验证、找回密码、资料编辑和会话管理页面。
- 无邀请码公开注册、原生 App、开放 API、微服务、Redis、搜索服务和对象存储。

这些能力不能出现在导航、空状态或演示数据中，也不能写成当前产品承诺。是否实现应由后续独立任务重新确认需求和安全边界。

## 产品原则

- 先保证诗作可以长期、安全地保存和阅读，再考虑互动功能。
- 首页和文案以真实班级来源为准，不虚构社团活动、作品数量或用户关系。
- 普通成员只能管理自己的内容；隐藏按钮和页面入口不能代替服务端授权。
- 用户文本默认按不可信纯文本处理，所有列表必须分页或使用固定小上限。
- 被禁用账号仍能理解自己的状态并访问允许的只读内容。
- 管理行为应可追溯，失败操作不得产生成功审计记录。

## 当前成功标准

- 游客可以稳定完成首页浏览、诗作分页浏览和详情阅读。
- 受邀同学可以完成注册、登录、创建草稿、编辑、发布、撤回和草稿删除。
- 管理员可以完成诗作、用户、角色、邀请码和审计治理，且不能绕过最后管理员等安全约束。
- 草稿、撤回和隐藏内容不会泄露到公开读取，跨用户访问不能读取或修改他人私有内容。
- 页面在约 390px 至 1440px 视口内可读、可操作且无水平溢出。
- 数据库 migration 可重建，规定的类型检查、lint、测试和生产构建保持通过。
