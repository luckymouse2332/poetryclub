# 产品文档：回中诗社

## 产品定位

回中诗社是面向回中三班 2021—2024 级同学的原创诗作与共同记忆线上归档。网站保存同学们写下的诗、打油诗及相关创作背景，并提供稳定、克制的公开阅读体验。

产品服务于一个边界明确的熟人群体，不以扩大用户规模、提高互动频率或形成通用校园社交平台为目标。首页的诗集合照、年级标识和介绍文字共同说明这一身份来源。

## 当前用户与权限

- 游客无需登录即可查看首页、分页诗作列表和公开诗作详情。
- 持有效邀请码的同学可以注册为成员。注册后需用邮件验证码验证邮箱，再显式登录；验证不会自动建立会话。
- 正常成员可以创建草稿、编辑自己的诗作、发布、撤回，以及删除未发布草稿。
- 正常成员可以为作品选择公开或仅成员可见；管理员可以读取两类已发布作品，游客只能读取公开作品。
- 正常成员可以创建自己的特辑草稿，把当前有权阅读的已发布诗作按顺序收录，并选择公开或仅成员可见后发布。
- 游客可以阅读公开作品的评论；正常成员和管理员可以在自己有权阅读的已发布作品下发布根评论与一级回复，并编辑或软删除自己的可见评论。
- 被禁用成员保留登录与只读访问，可以查看自己的既有诗作和禁用原因，但不能执行写操作。
- 正常管理员可以管理诗作与评论可见性、用户状态与角色、邀请码和审计记录。管理员权限始终由服务端权威状态决定。

## 当前核心流程

### 公开阅读

1. 游客进入首页，看到诗社介绍、诗集合照和最近发布的三篇诗作。
2. 游客进入诗作列表，按首次发布时间倒序分页浏览。
3. 游客打开诗作详情，阅读标题、正文、作者、创作背景和事件日期等公开信息。

正常成员和管理员在相同首页、列表和详情入口中还可以阅读作者标记为“仅成员可见”的已发布作品。被禁用成员不具备成员作品读取资格。游客直达成员作品时只会看到登录提示，不会收到作品内容或标题。

只有处于已发布状态、未被管理员隐藏且具有发布时间的诗作能够进入公开页面。草稿、已撤回或已隐藏诗作对公开访问统一不可见。

### 注册与登录

1. 用户在登录页切换到注册表单，填写昵称、邮箱、密码和邀请码。
2. 服务端校验并原子消费邀请码，创建成员账号；无效、过期、停用或用尽的邀请码不会创建账号。
3. 创建账号后向邮箱发送 5 分钟有效的 6 位验证码；验证完成前不能使用密码登录。发送失败或验证码过期时可以重新发送。
4. 已注册用户可使用邮箱密码或邮箱验证码登录，并进入安全的站内返回地址。验证码登录不得自动创建账号，也不能绕过邀请码。
5. 用户可以查看最小账户信息并主动登出；登出会使当前服务端会话失效。
6. 已登录用户可以在账户安全页验证当前密码并修改密码；成功后当前浏览器会话保留，其他会话失效。
7. 忘记密码用户可以提交邮箱并收到统一提示。已注册邮箱会收到一小时有效、只能使用一次的重置链接；重置成功后全部旧会话失效，用户使用新密码重新登录。

### 诗作管理

1. 正常成员创建一篇纯文本草稿，必须选择公开或仅成员可见，并可填写标题、正文、创作背景和事件日期。
2. 成员在“我的诗作”中分页查看草稿和已发布诗作，并编辑自己的内容。
3. 草稿发布后按访问范围进入首页、列表和详情；撤回后立即退出所有读者读取，但保留首次发布时间。
4. 只有未发布草稿可以由作者删除，已发布作品需要先撤回。

正文以纯文本保存和展示，保留换行与空行，不接受未经净化的 HTML。

### 作品评论

1. 读者在诗作详情按线程活动时间浏览根评论，每批十条，每条预览最近三条一级回复。
2. 正常成员和管理员使用幂等提交标识发布评论或一级回复；同一账号的新发布受十秒冷却限制，Redis 故障时不阻断 PostgreSQL 写入。
3. 评论作者可以长期编辑未删除、未隐藏的评论。删除会清空正文并保留结构占位，已有回复继续显示，删除不可恢复。
4. 完整讨论页默认显示最近二十条回复，并按时间正序排列；通知链接可以定位并突出显示目标评论。

评论继承所属诗作的访问范围，成员作品的标题和评论正文不会写入评论通知。评论与回复只按纯文本渲染。当前界面只支持一级回复，数据库结构保留后续扩展更深层级的能力。

### 诗作特辑

1. 正常成员创建特辑草稿，填写纯文本标题、简介和访问范围，再从当前可读的已发布诗作中建立有序目录。
2. 公开特辑只能收录公开诗作；仅成员特辑可以收录公开或仅成员可见诗作。发布至少需要一篇当前有效的作品。
3. 读者在分页目录中选择作品，逐篇阅读时可以前往上一篇、下一篇、返回目录或进入原作品详情与评论。
4. 已收录作品后来撤回、被隐藏或与特辑访问范围不兼容时，公开目录和连续阅读会直接跳过，不显示标题、占位或原始收录数量。
5. 整理者可以继续编辑已发布特辑，也可以撤回；只有从未发布的草稿可以删除。特辑不改变原作品的作者、正文、评论或访问设置。

特辑本身沿用 `public | members_only` 访问范围和 `visible | hidden` 治理状态。游客直达成员特辑时只收到不含标题和简介的登录门槛；suspended 账号只能读取公开特辑，不能管理自己的特辑。

### 管理治理

1. 管理员可以隐藏或恢复诗作，并记录原因、操作人和时间。隐藏状态独立于作者的草稿或发布状态。
2. 管理员可以禁用或恢复用户、调整成员与管理员角色；系统阻止自我破坏性操作和移除最后一名正常管理员。
3. 管理员可以创建、查看和停用邀请码。邀请码明文只在创建成功时显示一次，数据库仅保存哈希。
4. 管理动作与审计日志在同一事务内写入；审计记录只读，不提供编辑或删除入口。
5. 管理员可以隐藏或恢复未删除评论，必须填写原因；治理状态、作者通知和审计记录在同一事务内写入。管理员不能编辑用户评论正文。
6. 管理员可以隐藏或恢复特辑并填写原因；治理状态、整理者通知和审计记录在同一事务内写入，管理员不能代替整理者修改标题、简介、目录或发布状态。

## 已实现范围

- 邀请码注册、邮箱验证、邮箱密码与验证码登录、权威服务端会话、幂等登出、修改密码和邮件密码重置。
- `member | admin` 最小角色，以及 `active | suspended` 账号状态。
- 诗作草稿、编辑、发布、撤回、草稿删除、公开分页列表和详情。
- `visible | hidden` 诗作治理状态，以及用户、角色、邀请码和审计管理。
- `public | members_only` 诗作访问范围，active 成员作品读取和游客登录门槛。
- 暖纸色首页、诗集合照、最近诗作索引、响应式导航、关于项目手记、隐私政策和使用条款页面。
- 站内通知中心、系统公告草稿与发布、公告收件人快照、成员公告详情阅读、未读状态和 Redis/SSE 实时唤醒。
- 作品根评论、一级回复、编辑、软删除、游标分页、评论计数、通知定位和管理员评论治理。
- 成员特辑草稿、访问范围、有序收录、分页目录、逐篇连续阅读和管理员特辑治理。
- 版本化数据库 migration、生产容器部署和宿主机反向代理边界。

准确的里程碑与验收记录见 `docs/tasks/README.md`。

## 当前未实现范围

- 点赞、收藏、分享、匿名评论、任意层级回复界面和评论个人主页。
- 私信、实时聊天、关注关系和推荐算法。
- 标签、全文搜索、作品或特辑封面、附件、富文本或 Markdown 编辑。
- 文章模型、共同整理特辑、收录确认和收录通知。
- 班史时间线、人物档案和活动组织功能。
- OAuth、资料编辑和独立会话管理页面。
- 无邀请码公开注册、原生 App、开放 API、微服务、搜索服务和对象存储。

这些能力不能出现在导航、空状态或演示数据中，也不能写成当前产品承诺。是否实现应由后续独立任务重新确认需求和安全边界。

## 产品原则

- 互动功能保持轻量，不能削弱诗作的长期保存、访问边界与阅读体验。
- 首页和文案以真实班级来源为准，不虚构社团活动、作品数量或用户关系。
- 普通成员只能管理自己的内容；隐藏按钮和页面入口不能代替服务端授权。
- 用户文本默认按不可信纯文本处理，所有列表必须分页或使用固定小上限。
- 被禁用账号仍能理解自己的状态并访问允许的只读内容。
- 管理行为应可追溯，失败操作不得产生成功审计记录。
- 密码重置请求不得泄露邮箱是否注册；密码、会话凭据和完整重置令牌不得进入页面文案、客户端持久化或应用日志。

## 当前成功标准

- 游客可以稳定完成首页浏览、诗作分页浏览和详情阅读。
- 受邀同学可以完成注册、登录、创建草稿、编辑、发布、撤回和草稿删除。
- 用户可以完成修改密码和邮件找回密码，旧密码与旧会话按对应安全规则失效。
- 管理员可以完成诗作、用户、角色、邀请码和审计治理，且不能绕过最后管理员等安全约束。
- 有权阅读作品的读者可以读取对应评论，正常成员可以完成评论、一级回复、编辑和软删除，管理员评论治理可追溯。
- 正常成员可以管理自己的特辑，读者只看到当前有权读取的有效目录项目，管理员特辑治理可追溯。
- 草稿、撤回、隐藏和成员作品不会泄露到无权读取，跨用户访问不能读取或修改他人私有内容。
- 页面在约 390px 至 1440px 视口内可读、可操作且无水平溢出。
- 数据库 migration 可重建，规定的类型检查、lint、测试和生产构建保持通过。
