# 产品文档：回中诗社

## 项目定位

回中诗社是一个面向校园的诗歌兴趣社区。目标是在校园内提供一个分享原创诗歌、互相评论、结识同好的线上角落，让诗意留在校园。

## 目标用户

- 在校学生（中学 / 大学）：对诗歌创作、朗读、鉴赏有兴趣的同学。
- 校园文学类社团成员：希望有一个线上阵地发布作品、组织活动。
- 轻度读者：只想浏览和欣赏他人作品的普通学生。

## MVP 核心流程

1. 用户注册 / 登录，进入社区。
2. 浏览社区广场的诗歌作品列表（分页）。
3. 发布自己的原创诗歌作品。
4. 对作品发表评论。
5. 对作品点赞 / 收藏。

## MVP 范围

- 基础账号体系（最小登录框架，不包含复杂 OAuth 与权限系统）。
- 诗社 / 社区模型与首页。
- 作品（post）发布与分页列表。
- 评论与点赞。
- 基础通知（MVP 后期按需）。

## M0 目标（工程基线）

- 可运行、可测试、可持续扩展的工程基线，不包含任何业务功能。清单与状态见 `docs/tasks/M0-engineering-baseline.md`。

## 明确非目标（MVP 阶段不做）

- 私信
- 实时聊天
- 推荐算法
- Redis
- 搜索引擎
- 对象存储
- 复杂后台管理
- AI 功能
- 原生 App、开放平台、微服务

## MVP 成功标准

- 用户能完成：注册登录 → 浏览作品列表 → 发布作品 → 评论 / 点赞。
- 所有列表均分页，无可观察的性能问题。
- 每个服务端入口都执行认证、授权、输入校验与错误处理。
- 数据库拥有完整、可重建的 migration 历史。
- `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 全部通过。
