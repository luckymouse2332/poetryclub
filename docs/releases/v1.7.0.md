# v1.7.0：纸刊界面与使用体验

本版本更新全站纸刊界面，新增深色模式和邮箱验证码登录，并完善创作、评论、通知与管理操作。现有账号和内容保留。

## 新功能与体验

- 统一暖纸底色、宋体标题、连续目录及阅读纸页，优化手机、平板和桌面的排版、留白与导航。
- 支持跟随系统或手动切换深浅主题，浏览器记住选择，刷新与继续浏览时保持一致。
- 登录支持邮箱验证码，新账号注册需完成邮箱验证；原有密码登录、邀请码准入与找回密码流程继续可用。
- 整理诗作、特辑和公告编辑器及常用操作，完善未保存修改提醒，并修复编辑后发布与排序/分页状态反馈。
- 优化评论与通知的同步、断线恢复和跨标签已读状态。

## 工程与安全

- 复用现有 shadcn 原语及具名版式组合，统一 Card 列表变体与邮件模板。
- 增加格式/类排序、CSS 和语义样式检查，无新增运行时 CSS 依赖；本地 output 与 overnight 产物不进入版本控制。
- 强化管理页面、写操作及事务内权限重验，完善内容写入、账号停用、管理员治理和通知状态的并发保护。
- 修复认证表单水合前的原生提交行为，并集中转义邮件内容。

## 部署与回滚

必须先执行 **drizzle/0008_grandfather-existing-email.sql**，再启动新认证代码。迁移将升级前已有密码账号视为已验证，保留原有登录能力；新注册账号通过邮箱验证。

无新增环境变量，沿用已有邮件、PostgreSQL 和 Redis 配置。生产迁移前按部署流程备份数据库。应用回滚保留原有用户、内容与迁移记录，不自动逆转已验证历史标记。
