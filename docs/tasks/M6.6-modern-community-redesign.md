# M6.6：全站现代社区界面重设计

## 背景

用户要求先提交已有修改，再在当前分支全面优化前端。确认采用白色、浅灰与蓝色的清爽现代社区风格，覆盖公开页面、认证、成员工作区、通知与管理后台。

后续验收：用户否决本任务的现代社区视觉，要求校园纸本诗刊与全部基础组件重设计，由 M6.7 替代。本记录保留实现与测试历史，不代表该风格已获得用户认可。

## 范围

- [x] 重建全站视觉 Token、控件、标题、导航与响应式骨架。
- [x] 重设计首页、诗作、特辑、阅读、关于与政策页面。
- [x] 统一认证、编辑器、成员工作区、通知与管理界面。
- [x] 更新旧视觉断言，验证关键流程、键盘操作与多尺寸布局。
- [x] 同步设计规范与任务状态。

## 非目标

- 不增加搜索、收藏、推荐等产品功能。
- 不改变数据结构、权限、分页、内容可见性、认证与写入规则。
- 不推送、不发布、不创建标签。

## 架构边界

保持 app → features → server 与 components → lib。默认 Server Components；复用现有 shadcn/Radix 组件，不新增自制无头原语。用户文本保持纯文本。所有写入口沿用既有独立授权与校验。

## 实施记录

- 重建白色 / 浅灰 / 蓝色 Token、44px 控件、现代标题、卡片和导航；诗名与正文保留衬线。
- 首页采用真实合照的图文首屏，公开诗作与特辑使用卡片，阅读区与政策页使用独立白色表面。
- 认证、账户、内容编辑、通知与管理后台统一视觉；编辑器在 xl 起双栏，手机使用更紧凑的正文输入高度。
- 保留分页、原有操作与服务端权限，未增加业务功能、数据库或依赖变更。
- 增加跳转正文链接、减少动画支持与输入边界状态验证；默认边框置于 CSS base 层，使控件自己的状态样式有效。
- E2E 使用 `.next/e2e` 独立缓存，避免已打开的开发服务占用同一锁；生产环境仍使用 `.next`。
- 更新设计系统、产品现状与旧视觉断言；浏览器截图位于 `output/playwright/redesign/`（忽略目录）。

## 验证记录与已知限制

- `pnpm check:conventions`、`pnpm typecheck`、`pnpm lint` 通过；30 个测试文件、279 项单元测试通过。
- 全量浏览器回归 86 项通过，覆盖认证、访问控制、内容写入、评论、特辑、通知与治理。
- 最终界面回归 24 项通过（含输入边界、键盘跳转与减少动画）；边框修复后再次运行 `pnpm build`，编译、类型检查与全部路由生成通过。
- 多尺寸检查覆盖 27 个公开、成员与管理入口 × 390、768、920、1024、1440px；包含首页、登录、列表、编辑器和后台截图人工检查。
- 开发模式观察到 Radix 隐藏单选输入的内联样式 hydration 警告（margin 简写 / 展开样式差异）。单选控件及提交流程回归通过；没有使用 `suppressHydrationWarning` 隐藏警告，也未更改上游原语或依赖。
- 构建邮件配置仅在验证进程中使用占位值，不写入环境文件，不发送真实邮件。
