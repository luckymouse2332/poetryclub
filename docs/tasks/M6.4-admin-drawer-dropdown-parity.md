# M6.4 管理 Sheet 与桌面 Dropdown 对齐

## 背景

移动端管理入口目前只能进入后台总览，进入管理页面后仍依赖正文顶部的横向二级导航。上一轮迁移留下了未闭合的 Vaul Drawer 调用和依赖，本任务将全站移动导航收口到 shadcn/ui Sheet，并完成管理入口、账户通知状态和桌面浮层的导航一致性。

## 范围

- [x] 通过 shadcn/ui CLI 生成 `Sheet`，映射项目 Token、移除 `dark:` 变体，并为 `SheetContent` 保留 `overlayClassName` 扩展。
- [x] 把移动全站导航改为受控 Sheet；遮罩和面板从移动顶栏下方开始，汉堡按钮原位切换为关闭按钮。
- [x] 打开时焦点保留在原位按钮，Tab / Shift+Tab 可进入导航首尾项目；Escape、外部点击和链接跳转关闭，关闭后焦点回到触发器。
- [x] 在正常管理员可见的移动导航中加入可折叠的管理后台二级菜单，复用现有管理员导航数据与 active 语义。
- [x] 恢复移动账户圆标的未读通知红点，并在账户菜单中继续提供通知数量和入口。
- [x] 隐藏小于 `lg` 的管理后台顶部横向导航；`lg` 到 `xl` 保留紧凑导航，`xl` 起使用常驻侧栏。
- [x] 让桌面账户与通知 Dropdown 使用相同暖纸表面和自上向下展开动效。
- [x] 删除 Vaul 依赖、Drawer 接口和残留选择器，更新权限、响应式、键盘和回归测试。

## 非目标

- [x] 不删除全站移动 Header；汉堡菜单、站名和账户入口继续保留。
- [x] 不迁移 Alert、Item、Pagination，不处理全局 Token 与 UI 类名架构；这些内容由 `CHORE-style-architecture-consolidation` 承担。
- [x] 不引入新的动画库，不修改管理员权限守卫、通知实时逻辑、管理路由或服务端业务行为。
- [x] 不修改账户工作区的正文内二级导航。

## 架构边界

管理员导航继续使用 `ADMIN_NAV_ITEMS` 作为单一数据源。管理权限仍由服务端 `AuthNavigation` 和管理布局守卫判定，Sheet 只接收已判定的布尔状态。WorkspaceShell 只扩展响应式展示类，不改变页面业务组合。移动导航使用 CLI 生成的 `src/components/ui/sheet.tsx`，仅做 Token 映射和 `overlayClassName` 扩展。

## 验收条件

- [x] 正常管理员的移动 Sheet 显示可折叠的管理后台分组；展开后可访问总览、诗作、用户、邀请码、公告和审计，普通成员不显示该分组。
- [x] Sheet 遮罩和面板从移动顶栏下边缘开始，顶栏保持清晰且原位关闭按钮始终可操作。
- [x] 打开时焦点保留在原位关闭按钮；Tab / Shift+Tab 可循环访问导航内容，Escape、外部点击和链接跳转关闭，关闭后焦点归还。
- [x] 有未读通知时账户圆标显示单个暗红点，无未读时不显示；通知数量和入口仍位于账户菜单内。
- [x] 小于 1024px 的管理页面不显示正文顶部管理导航；1024–1279px 保留紧凑导航，1280px 起恢复常驻侧栏。
- [x] 桌面账户与通知 Dropdown 使用相同向下展开动画和视觉表面，不使用桌面背景遮罩或模糊；通知实时行为保持不变。
- [x] reduced-motion 下位移与缩放被取消，测试不依赖 Vaul 属性或旧的全局类名。

## 发布影响

- 预期版本影响：`PATCH`
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：可分别回滚 Sheet、管理分组、WorkspaceShell 响应式类和账户 Dropdown 样式。

## 测试

已补充 Sheet 组件单元测试并更新相关 E2E；已验证 390、1024、1280px、普通成员与管理员权限、焦点循环、外部点击、Escape、路由关闭、reduced-motion、账户 Dropdown 和通知 Popover。`check:conventions`、typecheck、lint、220 个单元测试和生产构建通过。

## 风险 / 回滚

主要风险是原位关闭按钮位于 Sheet 的焦点范围外，或移除移动顶部导航后在中等宽度产生不可达区间。通过受控状态、Radix 焦点事件和分段断点验证；管理二级“诗作”使用管理前缀可访问名称，避免与公共诗作入口混淆。
