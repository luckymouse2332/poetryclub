# M3.13 首页正文内容区布局收敛

## 背景

首页 Hero 下方的“最新诗作 / 关于回中诗社”已经采用双栏结构，但当前内容容器最大宽度为 1536px，栏间距也会随视口继续放大。桌面端因此显得过于铺开，两栏缺少共同的居中正文区域，右栏正文行宽也偏松散。本任务依据现有首页视觉语言与设计系统，对该区域的容器、栏宽和间距进行收敛。

## 范围

- [x] 为首页下半区建立最大宽度约 1240px、水平居中的统一内容容器。
- [x] 将桌面双栏调整为约 41% / 59%，并将栏间距限制在 64px 至 88px。
- [x] 将右栏正文限制在 40rem 至 44rem 的长文可读宽度内。
- [x] 更新首页响应式 E2E 断言，并完成桌面、平板和手机视口核对。

## 非目标

- [x] 不修改 Hero、暖米白配色、衬线字体、标题短横线和细分隔线。
- [x] 不改成卡片布局，不增加阴影、圆角、大面积边框或新的 UI 组件。
- [x] 不修改公开诗作查询、数据库、认证、授权或其他业务逻辑。

## 架构边界

首页继续保持 Server Component，现有公开诗作查询和页面语义结构不变。本任务只调整 `src/app/home.module.css` 的局部布局，并在 `tests/e2e/home.spec.ts` 中补充可计算的容器、栏宽、间距和溢出断言。样式继续使用现有 CSS Module 与全局语义 Token，不新增客户端状态或组件依赖。

## 验收条件

- [x] 桌面端内容容器最大宽度不超过 1240px，并在视口中水平居中。
- [x] 桌面端容器左右内边距位于 32px 至 48px，两栏比例约为 41% / 59%。
- [x] 桌面端栏间距位于 64px 至 88px，右栏正文最大宽度为 43rem。
- [x] 低于 1024px 时保持单栏堆叠，375px、768px、1024px 和 1440px 均无横向滚动。
- [x] `pnpm typecheck`、`pnpm lint`、`pnpm test`、本任务响应式 E2E 与 `pnpm build` 通过。

## 测试

已更新 `tests/e2e/home.spec.ts`，验证内容容器居中和最大宽度、桌面内边距、双栏比例、栏间距、右栏正文宽度、单栏顺序与横向溢出。

- `pnpm typecheck`：通过。
- `pnpm lint`：通过。
- `pnpm test`：11 个测试文件、187 项测试全部通过。
- `pnpm build`：Next.js 16.2.12 生产构建通过。
- 首页响应式 Playwright：375px、768px、1024px、1440px 共 4 项全部通过。
- 生产页面实测：1440px 下容器宽 1240px、内边距 43.2px、栏间距 72px、左栏占 41.0%；1024px 下内边距 32px、栏间距 64px、左栏占 41.0%；768px 和 375px 均为单栏且无横向滚动。
- 生产截图：`output/playwright/m3.13-home-375.png`、`m3.13-home-768.png`、`m3.13-home-1024.png`、`m3.13-home-1440.png`。

完整 `tests/e2e/home.spec.ts` 首次运行时有 8 项通过、6 项失败。失败来自当前工作树中更大范围首页 / About 改造留下的旧断言：旧 Hero 文案定位器和仍期待 `/#about` 的导航测试。本任务已将所涉及的 Hero 标题定位器对齐当前实现；基本内容测试仍期待已经删除的旧介绍句，导航测试仍期待旧锚点行为。两处均未在本布局任务中扩展修改。

## 风险 / 回滚

主要风险是 1024px 断点附近可用宽度不足，导致左栏内容拥挤或网格溢出。桌面列宽保留最小值，窄于 1024px 继续使用单栏。回滚时恢复首页 CSS 和对应 E2E 断言即可，不涉及数据迁移。
