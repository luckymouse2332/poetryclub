# M3.6 首页图片占比与文字链接反馈

## 背景

M3.5 修正了锚点滚动与过强的诗作行 hover。用户进一步要求桌面端右侧诗集合照占据更高比例，并明确保留文字链接的箭头位移和下划线反馈。

## 范围

- [x] 缩窄桌面端首屏左侧纸面，让右侧图片占据约六成可见宽度。
- [x] 保留当前文字位置和不规则纸张边缘。
- [x] 恢复“随便翻翻”和“查看全部”的箭头位移动效。
- [x] 保留链接下划线反馈，诗作列表行继续保持静态。
- [x] 更新浏览器测试并复核桌面视口。

## 非目标

- [x] 不恢复诗作列表整行的背景、阴影或变色 hover。
- [x] 不调整移动端首屏图文顺序。
- [x] 不改变锚点滚动、路由、查询或认证逻辑。

## 架构边界

首页继续保持 Server Component。视觉变化限定在首页 CSS Module 与既有 Link 类名，不增加 Client Component 或第三方动画依赖。

## 验收条件

- [x] 1024 与 1440 像素视口中左侧纸面宽度不超过视口的 45%。
- [x] 右侧图片容器在桌面端至少覆盖视口宽度的 68%。
- [x] 两个文字链接 hover 或键盘聚焦时箭头平滑右移。
- [x] “查看全部”链接 hover 时出现下划线。
- [x] 诗作列表行 hover 样式仍与静止状态相同。
- [x] typecheck、lint、Vitest、首页 E2E 和生产构建通过。

## 测试

更新首页 Playwright，检查桌面端图文容器比例、箭头 transform、下划线颜色和诗作行静态状态。运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、首页 E2E 与 `pnpm build`。

验证结果：1024 与 1440 像素下左侧纸面容器分别约占视口 42% 和 44%，图片容器分别约占 73% 和 68%；不规则裁切后可见图片从约四成视口处开始。大标题在 1024 像素下保持单行。两个文字链接的箭头 transform 与“查看全部”的下划线颜色变化均通过浏览器断言。

`pnpm typecheck`、`pnpm lint`、187 项 Vitest、14 项首页 Playwright 和 `pnpm build` 均通过。浏览器截图复核了 1024 与 1440 像素视口。

聚焦复核未发现阻断级或严重问题。

## 风险 / 回滚

图片比例只在 64rem 以上生效。回滚时恢复首屏两处 grid column 和纸面底部裁切点，并删除文字链接的动画类。
