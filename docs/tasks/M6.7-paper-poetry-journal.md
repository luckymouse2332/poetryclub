# M6.7：校园纸本诗刊与全基础组件重设计

## 背景

用户否决 M6.6 的现代社区风格，明确要求重新设计全部基础组件而非换色。已确认纸本校园诗刊方向，直接全站实施。

## 范围

- [x] 重建暖纸、墨色、宋体标题与方正形态的设计语言。
- [x] 逐一重设计 22 个基础组件及其状态与组合。
- [x] 覆盖首页、公开阅读、认证、成员、通知、评论和管理后台。
- [x] 增加仅 E2E 开放的组件展示与全状态浏览器验收。
- [x] 同步文档、视觉断言与任务记录。

## 非目标

不增加产品功能，不更改内容、权限、数据库、分页、服务端写规则；不推送或发布。

## 架构边界

保持 app → features → server、components → lib。页面只组合 UI；新增展示页面仅在 POETRYCLUB_E2E=1 时开放，普通运行返回 404。组件沿用现有 shadcn/Radix 原语与公共接口、data-slot、asChild、cn；默认 Server Components。

## 验收条件

- [x] 22 个组件都有明确的形态、排版、分区或状态调整记录。
- [x] 390、768、920、1024、1440px 无水平溢出，浮层、长文本与所有重要状态可操作。
- [x] 键盘、焦点回归、错误反馈、pending 防重和减少动画保持有效。
- [x] 全质量检查、全量浏览器回归与生产构建通过。

## 发布影响

- 预期版本影响：PATCH。
- migration / 环境变量 / 部署顺序：无生产变更；复用既有 E2E 标识。
- 兼容性与回滚边界：公共业务和组件接口保持兼容；原修改已保存为 960585c，界面修改未提交。

## 测试

更新组件快照和视觉断言；组件展示覆盖全部变体及普通、悬停、焦点、选中、错误、禁用、加载。人工查看真实浏览器截图。运行 check:conventions、typecheck、lint、test、完整 E2E、build。数据库测试仅使用显式独立测试库。

## 风险 / 回滚

组件覆盖广，页面局部覆盖类可能抵消新规范，需逐页检查。保持 Radix 行为，不以抑制警告或移除业务断言通过测试。保留测试缓存隔离和跳转正文等有效修复。

## 实施记录

- 设计系统第 10 节逐项记录 22 个组件的新造型、分区、字体和状态；沿用上游结构与接口，无新增依赖或原语。
- 以暖纸、墨色和低饱和墨绿重建 Token；品牌与编辑强调使用印章红，危险状态保持独立语义。内容直角，控件 2px，浮层 4px，卡片无默认投影。
- 首页采用宋体刊头、现有真实诗集照片与目录行；诗作、特辑、评论、通知和成员列表使用细线分区。认证采用窄版表单，编辑器桌面分栏、手机顺序呈现。
