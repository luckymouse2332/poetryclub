# M6.3 移动端导航浮层与动效修正

## 背景

M6.2 已完成移动端导航职责拆分，但账户菜单打开后页面背景缺少空间连续性，头像旁的无文字红点含义不够明确，菜单开合也缺少符合方向关系的运动反馈。本任务根据移动端实机截图继续收敛浮层呈现。

## 范围

- [x] 为移动端全站菜单和账户菜单增加保留页面内容的背景模糊遮罩。
- [x] 为全站抽屉增加从左向右、顶栏下方推入的动效；账户菜单从上向下展开。
- [x] 移除头像旁的未读红点，将通知入口和明确未读文字移入移动账户菜单。
- [x] 更新相关 E2E、设计系统说明与视觉 QA。

## 非目标

- [x] 不修改桌面导航、桌面通知 Popover 或账户菜单的信息架构。
- [x] 不修改认证、通知服务、实时更新、权限判断或数据库结构。
- [x] 不新增头像功能、通知类型或业务状态。

## 架构边界

通知数量继续由 AuthNavigation 服务端读取并作为最小视图数据传入客户端账户菜单。背景遮罩与动效扩展现有 shadcn/ui Dialog 和 DropdownMenu 组合，保留 Radix 的 Portal、焦点管理、键盘行为与外部点击关闭语义。

## 验收条件

- [x] 移动端菜单打开后仍能辨认原页面结构，背景被轻度压暗并模糊，而非替换为纯色页面。
- [x] 移动端头像不显示无说明红点，账户菜单内存在“通知”入口及明确的未读说明。
- [x] 全站抽屉从顶栏下方向右推入，顶栏原位保留且汉堡按钮切换为叉；账户菜单从上向下展开，关闭方向与打开相反。
- [x] reduced-motion 环境下取消位移、缩放和模糊过渡，菜单仍可正确显示和关闭。
- [x] 桌面端通知与“我的”菜单保持现有行为。

## 发布影响

- 预期版本影响：`PATCH`
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：可按浮层样式、移动账户菜单入口和测试独立回滚。

## 测试

更新移动导航与通知 E2E，验证背景遮罩、通知入口、未读文案、动画方向、外部点击、Escape、焦点归还与 reduced-motion；运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、相关 Playwright 和 `pnpm build`。

## 风险 / 回滚

主要风险是 DropdownMenu 自定义遮罩影响外部点击，以及 Dialog 的退出动画被 Portal 提前卸载。通过 Radix data-state 和现有受控 open 状态验证；如出现回归，可撤回可选 backdrop 属性与专用动画类。
