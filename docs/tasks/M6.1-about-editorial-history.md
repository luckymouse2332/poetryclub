# M6.1 About 沿革叙事重构

## 背景

整站已经形成暖纸色、中文编辑排版和班级档案式的视觉语言，但 `/about` 仍以重复的章节模板串联网站介绍、技术记录与计划，更新记录的权重也高于诗社自身的沿革。本任务只重组 About 页面的叙事与排版，使其按“过去 → 现在 → 未来”自然阅读。

## 范围

- [x] 将页面顺序调整为序言、四次迁徙、现在、未来、更新记录附录。
- [x] 让历史、现在、未来和附录分别使用纵向沿革、横向分栏、编辑网格和紧凑修订记版式。
- [x] 保留现有静态资料与历史链接，只压缩 About 页面实际展示的更新记录和计划细节。
- [x] 补充 390px、768px、1280px 与 1440px 的响应式检查和页面结构测试。

## 非目标

- [ ] 不修改 About 以外页面的业务逻辑或视觉实现。
- [ ] 不新增图片、动画、数据库结构、服务端接口或完整 changelog 系统。
- [ ] 不为历史和未来章节引入卡片、时间轴圆点、徽章或进度表达。

## 架构边界

`src/app/about/page.tsx` 继续只负责路由与 metadata；内容、静态数据和局部样式保留在 `src/features/about`。页面保持 Server Component，不新增客户端状态、数据库访问或服务端入口。样式只使用现有语义 Token、字体变量和响应式断点。

## 验收条件

- [x] 页面开头先说明回中诗社是什么、为什么仍被保留，不形成第二个首页 Hero。
- [x] “四次迁徙”是页面主要历史章节，桌面以年份和正文左右组织，移动端自然堆叠。
- [x] “现在它向时间敞开”使用宽屏三栏，“接下来准备做什么”位于更新记录之前并使用两列编辑网格。
- [x] 更新记录位于页面最后，只展示最近五条简要记录。
- [x] 各验收视口无水平溢出，长正文保持舒适行宽。
- [x] `pnpm typecheck`、`pnpm lint` 与 `pnpm build` 通过。

## 发布影响

- 预期版本影响：`MINOR`
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：不改变路由、数据结构或业务行为；可整体回滚 About 组件、样式、数据映射和对应测试。

## 测试

About 专项 E2E 共 2 项通过，覆盖章节顺序、四个历史阶段、最近五条更新记录、390px / 768px / 1280px / 1440px 分栏切换与水平溢出。视觉 QA 在四个视口完成全页截图，并对历史、现在、未来和附录分别捕获聚焦截图，`design-qa.md` 最终结果为 `passed`。

`pnpm check:conventions`、`pnpm typecheck`、`pnpm lint`、`pnpm test` 与 `pnpm build` 均通过；单元测试为 16 个文件、208 项测试全部通过。构建期间没有启动或停止开发服务器，构建完成后现有 `http://127.0.0.1:3000/about` 仍返回 200。

## 风险 / 回滚

主要风险是长页在中等宽度下年份列挤压正文，或两列计划在窄屏产生过短行宽。布局采用移动优先，并仅在空间充足时启用多栏；回滚不涉及数据迁移。
