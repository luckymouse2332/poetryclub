# M6.9 背景与纸面层次增强

## 背景

M6.8 收敛连续目录时将列表及行背景都设为透明，导致内容与外围背景融为一体。用户在实现过程中澄清：不能加深外围背景，Header/Footer 也不需要较强对比。最终恢复背景 #F3EEE4，Header、移动主导航与 Footer 共用此底色；通用表面保留 #FAF7F0，只将主内容纸面设为 #FFFDF8 并增加连续承载面，继续保留校园纸刊布局。

## 范围

- [x] 保留原外围底色、让 Header/Footer 与其共用，增强主内容纸面，公开、个人及后台列表使用连续浅纸面与统一内边距。
- [x] 特辑详情目录、空状态与分页边界同步调整，避免重复分隔线与嵌套铺底。
- [x] 五种屏宽与代表页面截图复核，更新实际样式断言与设计系统。

## 非目标

不新增产品功能、依赖、组件原语、数据库或服务端规则，不改变权限、路由及业务操作；不提交、推送或发布。
