# M3.8 登出按钮导航样式对齐

## 背景

登录态导航中的“登出”使用 shadcn Button 的默认尺寸与字重，和同栏的“诗作”“关于”“我的诗作”“账户”“管理”链接在字体、字号和字重上不一致。用户要求修复。

## 范围

- [x] 保留 Button 组件和服务端登出表单。
- [x] 让“登出”与导航链接共用字体、字号、字重、行高和水平内边距。
- [x] 保持 44px 最低点击高度与原有 hover / active 颜色。
- [x] 补强登录态浏览器测试。

## 非目标

- [x] 不改变登出 Server Action、会话或跳转逻辑。
- [x] 不把导航链接改成 Button，也不自实现新的 UI 组件。
- [x] 不调整匿名导航和移动端换行规则。

## 架构边界

`AuthNavigation` 继续作为 Server Component。登出操作继续使用现有 shadcn Button 和 Server Action，只通过项目 Token 类名覆盖导航场景的视觉尺寸。

## 验收条件

- [x] “账户”链接与“登出”按钮的高度、字体族、字号、字重、字距、行高和左右内边距一致。
- [x] “登出” hover 时不出现 Button 的背景色块，只使用与其他导航项一致的印章红文字。
- [x] 键盘仍能聚焦并提交登出按钮。
- [x] typecheck、lint、Vitest、认证 E2E 和生产构建通过。

## 测试

扩展 `tests/e2e/auth-flow.spec.ts` 登录态导航计算样式断言。运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、认证 E2E 与 `pnpm build`。

验证结果：登录态浏览器直接比较“账户”和“登出”的高度、字体族、字号、字重、字距、行高及左右内边距，结果完全一致。认证 E2E 的注册、登录、受保护页面、真实登出、重复登出接口和失效 Cookie 共 5 项全部通过。

同步移除了认证 E2E 中已经过时的“登录后首页显示欢迎语和写作按钮”断言，改为验证当前精简首页只在刊头提供“我的诗作”“账户”和“登出”。

`pnpm typecheck`、`pnpm lint`、187 项 Vitest、5 项认证 Playwright 和 `pnpm build` 均通过；聚焦复核未发现阻断级或严重问题。

## 风险 / 回滚

变化限定在登出 Button 的 className。回滚时恢复原有 `size="sm"` 与简化类名即可，不影响登出功能。
