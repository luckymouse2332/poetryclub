# BUG-17：管理列表重复分隔线移除

## 背景

用户反馈管理诗作列表的一行被标题、作者信息及操作栏的多条横线割裂，难以辨认行边界。

## 范围

- [x] 移除诗作、用户、邀请码、评论与审计列表的行内标题/页脚横线。
- [x] 用间距区分内容组，保留列表容器负责的行间分隔。
- [x] 核对管理列表截图与治理操作。

## 非目标

不修改基础 Card 的通用分区设计、状态标签、业务逻辑、权限、数据库或其他页面；不提交或推送。

## 架构边界

仅调整 features 中管理列表组合的样式；保留 Card 家族、data-slot、公共参数、原确认弹窗和 Server Actions。

## 验收条件

- [x] 每行标题、资料与操作之间无额外横线，行间边界清楚。
- [x] 长文本、小屏与危险操作仍可读、可操作。
- [x] 隐藏、恢复、用户治理、邀请码和审计行为不变。

## 发布影响

- 预期版本影响：无需单独发布。
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：只改组合样式，恢复 Header / Footer 的局部类即可回滚。

## 测试

更新已有管理页面的浏览器布局断言，运行管理治理与评论回归，人工查看列表截图；typecheck、lint、规范检查。

## 风险 / 回滚

不从基础 Card 全局移除横线，避免影响独立内容分区；列表行间线继续由现有列表容器负责。
