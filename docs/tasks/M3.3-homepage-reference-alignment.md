# M3.3 首页参考图对齐调整

## 背景

当前首页已经使用 `docs/mockups/诗集合照.jpg` 作为首屏实拍图，但刊头、标题间距、导航当前页提示和图文交界仍与用户提供的参考图存在差距。用户要求在充分阅读产品、架构、设计系统、既有首页任务与本地 Next.js 16 文档后，进一步简化首页并改善首屏构图。

## 范围

- [x] 简化站点刊头，并为当前路由提供可感知的导航标记。
- [x] 调整首屏标题与刊头的垂直间距，只保留必要文案和一个主要阅读入口。
- [x] 继续使用 `docs/mockups/诗集合照.jpg`，让桌面端左侧纸面以不规则边缘自然过渡到右侧照片。
- [x] 精简首页下方的重复说明，同时保留真实公开诗作查询与关于信息。
- [x] 更新首页 E2E 断言，并完成响应式视觉检查。

## 非目标

- [x] 不修改数据库 schema、migration、认证流程、权限规则或诗作查询契约。
- [x] 不新增动画库、图片资源、业务入口或 Client Component 业务逻辑。
- [x] 不修改发布分支、tag 或部署流程。

## 架构边界

首页继续作为 Server Component，只负责组合既有公开诗作 service 与静态展示。当前路由标记由独立的小型导航 Client Component 读取路径，组件不读取会话或数据库。认证导航继续在服务端获取最小用户视图，数据库访问仍位于 `src/server`。用户文本继续以 React 纯文本渲染。

## 验收条件

- [x] 桌面端刊头与主标题之间存在清楚留白，首屏只保留必要文案和一个阅读入口。
- [x] 首页、诗作、登录和账户等真实路由能够通过 `aria-current` 与可见标记表达当前位置。
- [x] 桌面端左侧纸面与照片采用不规则边缘衔接；移动端恢复自然上下排列且不裁切正文。
- [x] 首页只使用 `docs/mockups/诗集合照.jpg`，图片无拉伸且主要内容清楚可见。
- [x] 375、768、1024、1440 像素视口无横向滚动，键盘焦点清楚可见。
- [x] `pnpm typecheck`、`pnpm lint`、`pnpm test`、首页 E2E 与 `pnpm build` 通过。

## 测试

已更新 `tests/e2e/home.spec.ts` 中首页文案、导航当前页语义、浏览器错误和响应式布局断言。`pnpm typecheck`、`pnpm lint`、`pnpm test`、首页 14 项 Playwright 测试与 `pnpm build` 均通过。视觉截图位于 `output/playwright/m3.3-home-375.png`、`m3.3-home-768.png`、`m3.3-home-1024.png`、`m3.3-home-1440.png`。

聚焦复核未发现 P0、P1 或 P2 问题；残余风险主要是不同字体渲染环境下的不规则边缘观感差异。

## 风险 / 回滚

主要风险是桌面端 `clip-path` 造成文字裁切，或宽幅照片在中等视口出现不合适裁切。相关修改集中在首页、刊头和局部样式；回滚时可恢复这些展示文件，不涉及数据迁移。
