# BUG-15：首页首屏上下留白移除

## 背景

用户要求去掉首页图文首屏外侧的上下留白，让照片与导航下边界、首屏分隔线贴合。

## 范围

- [x] 移除首屏顶部外边距与底部内边距。
- [x] 验证照片与首屏边界贴合，保留锯齿页边与响应式布局。

## 非目标

不改变文字内部间距、后续内容区、颜色、业务功能和数据库；不提交或推送。

## 架构边界

只调整首页 CSS Module 和对应布局断言；不改变组件接口、服务端读取、权限和分页。

## 验收条件

- [x] 桌面首屏照片上沿贴合导航下沿，下沿贴合首屏分隔线。
- [x] 手机首屏底部无额外留白，所有视口无水平溢出。
- [x] 原锯齿页边、省略号、操作区域与键盘行为保留。

## 发布影响

- 预期版本影响：无需单独发布。
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：仅首页样式，可恢复原 margin / padding。

## 测试

更新现有首页布局断言，运行首页 E2E 并查看截图；运行规范检查、typecheck、lint。

## 风险 / 回滚

小屏图文上下排列，保留文字内部间距和图文间距，仅移除首屏外侧留白。回滚本任务的样式和对应断言即可。
