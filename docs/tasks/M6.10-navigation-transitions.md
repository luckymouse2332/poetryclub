# M6.10 导航跳转动画

## 背景

用户要求导航栏跳转时有动画。现有 Next 配置开启 View Transition，但没有 React 过渡边界；主导航选中线直接出现，二级导航只有未接入的 CSS 名称。

后续用户明确只需要导航栏动画，主页面不要动画。本轮移除主内容过渡边界与淡入、位移，仅保留导航选中线，先前包含页面动画的验收记录作为历史。

## 范围

- [x] 主内容直接切换，主导航与工作区选中线平滑移动；移除页面淡入淡出与位移。
- [x] 页头、页脚保持稳定，同页锚点沿用滚动行为；减少动态效果与不支持的浏览器正常跳转。
- [x] 验证真实动画、键盘、历史导航、移动菜单及减少动态效果，更新设计系统。

## 非目标

不增加动画依赖、等待计时器或产品功能，不修改业务、权限、背景配色、路由与数据库；不提交、推送、发布。

## 架构边界

使用已安装 Next 16.2 的 React ViewTransition 与原生浏览器能力。过渡仅位于现有导航组件，app 恢复直接组合页面内容；复用现有 Link，不手动拦截路由或实现导航状态机，不新增组件。

## 验收条件

- [x] 桌面主导航选中线实际产生约 220ms 过渡，主内容、页头页脚无跳转淡入或位移。
- [x] 二级导航、侧栏与移动菜单保持可达；键盘与前后退正常，动画不人为延迟导航。
- [x] 同页锚点、Ctrl/Meta 点击、减少动态效果与缺少 API 的回退正常；快速跳转不留下旧内容或重复过渡名。
- [x] 规范检查、类型检查、lint、单元测试、相关浏览器回归及生产构建通过。

## 发布影响

- 预期版本影响：无需单独发布。
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：沿用现有实验性 View Transition 配置，浏览器无支持时直接切换。回滚动画边界与 CSS，不影响业务。

浏览器观察真实 View Transition 动画，断言仅导航选中线有正时长动画、主内容无过渡边界；检查主导航、三种工作区断点、移动菜单、键盘、前后退、快速连续导航、减少动态效果和无 API 回退。执行规范检查、typecheck、lint、test、导航/首页 E2E、build。
