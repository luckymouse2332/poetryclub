# BUG-14：首页省略号与锯齿页边恢复

## 背景

用户要求在 M6.7 纸刊重设计中保留之前的长文本省略号与锯齿页边。首页目录的长诗名、作者目前换行，首屏照片移除了原页边。

## 范围

- [x] 恢复首页诗名与作者的单行省略，保留完整可访问名称和悬停标题。
- [x] 复用原有横向/纵向页边资源，适配当前暖纸色与响应式首屏。
- [x] 更新首页视觉验收和设计文档。

## 非目标

不改变纸刊整体设计、其他列表、内容、权限、路由、数据库和依赖；不提交、推送或发布。

## 架构边界

仅调整首页 CSS Module 和对应验收。图片装饰通过伪元素展示，不参与辅助技术和点击；保持 app 的页面组合及原有服务端读取规则。

## 验收条件

- [x] 长诗名、作者出现省略号，成员可见标记不被截断。
- [x] 小屏使用照片顶部横向页边，桌面使用左侧纵向页边；不产生横向溢出。
- [x] 全文名称、链接、44px 操作区、键盘焦点和减少动画保持有效。

## 发布影响

- 预期版本影响：无需单独发布。
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：公共接口不变；回滚本次首页样式与视觉断言即可。

## 测试

运行首页浏览器回归，覆盖长文本和不同视口，查看移动/桌面截图；运行 typecheck、lint、规范检查。沿用既有独立 E2E 数据库及缓存。

## 风险 / 回滚

原页边资源底色与新暖纸不同，因此使用其透明轮廓作为 CSS mask，避免出现不同色的纸条。仅视觉截断，保留 DOM 中全部文字与 title。

## 验证记录

- 首页 16 项 E2E 全部通过；超长诗名与作者覆盖 390、768、920、1024、1440px，验证实际截断、完整可访问名称与 title、44px 链接和无横向溢出。长文本为浏览器内临时样本，不修改已保存内容。
- 人工查看移动/桌面页边与目录截图，位于 `output/playwright/paper-journal/*-retained-*.png`。页边复用现有资源，无图片编辑或新依赖。
- typecheck、lint、check:conventions 通过；变更未提交、推送或发布。
