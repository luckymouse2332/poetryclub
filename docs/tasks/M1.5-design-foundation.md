# M1.5：视觉基础设施正式落地

## 背景

来源：产品给出的 Figma 设计（`https://www.figma.com/design/QdyP8Z9m6skhklm67oWzCN`）、`docs/mockups/website.png`、产品名称“回中诗社 / 2021—2024级”，以及 `docs/product.md`、`docs/architecture.md` 对 M1 后续前端演进的要求。

M1 已完成认证会话闭环，但当前界面仍使用工程基线的默认白色 / 靛蓝主题和系统字体，页面容器、表单与状态组件也没有统一契约。M1.5 只建立可供 M2—M4 复用的视觉与组件基础，不实现 Figma 效果图中的作品、班史、人物等业务。

仓库检查确认：项目使用 Tailwind CSS 4 的 CSS-first `@theme inline`、shadcn 目录约定，以及现有的 `clsx`、`tailwind-merge`、`class-variance-authority`、Radix Slot；本任务无需新增依赖。工作开始前已存在未跟踪的 `docs/design-system.md` 和 `docs/mockups/`，本任务将前者作为输入补齐和收敛，不删除后者。Figma 页面在当前环境返回 HTTP 403，因此实现以用户书面要求、参考效果图和现有设计文档为准，并保留 Figma 地址供人工复核。

## 架构边界

- `src/app` 保持薄层，只组合 `src/components` 与 `src/features`；纯 UI 和布局组件位于 `src/components`。
- 颜色具体值只能出现在 Token 定义处；业务组件仅使用语义类名，不写十六进制颜色或大量任意值类名。
- 保留现有 Tailwind 4、CVA、`cn` 和 shadcn 约定，不增加功能重叠依赖。
- `SiteHeader` 是纯 UI；认证状态仍由 `AuthNavigation` Server Component 读取一次并通过插槽注入，不在客户端获取会话。
- `logoutAction` 与 `src/server/auth/session.ts` 的授权、吊销和 Cookie 清理逻辑不改动。
- Header 只展示品牌、首页，以及随认证状态变化的登录或账户、登出；注册仍可在已实现的登录页内完成，但不增加额外导航入口。
- 用户可编辑内容仍按不可信纯文本处理；本任务不增加 HTML 渲染能力。

## 风险 / 回滚

- 已知风险：当前环境无法直接读取 Figma（HTTP 403），视觉细节依据参考效果图与书面规则实现；仍需设计人员人工对照 Figma。
- 已知风险：`next/font/google` 构建需要可访问字体源；本次生产构建成功，若后续离线构建不稳定，应另立任务评估项目托管字体文件，不得静默换字体。
- 已知风险：中文字体资源体积较大，当前使用可变字体、`display: swap` 和非预加载策略；后续应以真实性能数据决定是否优化。
- 已知风险：Button loading / disabled 暂无独立组件单元测试，但真实认证提交流程 E2E 已覆盖 loading 使用路径；可作为后续最小质量任务补充。
- 已知风险：首页当前使用语义 Token 绘制的校刊封面式校园插图，因为仓库没有已获授权的真实校园照片；未来替换真实图片必须单独确认授权、隐私和图片优化，不应在 M1.5 内临时引入外部素材。
- 已知风险：隐私政策和使用条款反映 2026-08-02 的当前实现；未来增加数据字段、公开内容、分析工具或账号管理能力时必须同步复核并更新页面。
- 已知风险：备案号链接依赖工信部外部站点；备案信息变化时必须同步更新 Footer 展示文本。
- 确认：本任务未修改 `src/server/db/schema`、`drizzle/` 或任何 migration，未执行破坏性数据库操作。
- 确认：本任务未定义诗作领域模型、查询、分页、草稿、发布、评论、收藏或通知，未进入 M2。
- 回滚：恢复 M1 页面和原始 `globals.css` / Button，删除本任务新增纯 UI 组件和文档；本任务没有数据库回滚步骤。
