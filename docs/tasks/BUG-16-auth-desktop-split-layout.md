# BUG-16：认证页桌面左右布局

## 背景

用户反馈登录页桌面空间利用率不足，要求采用左右布局。

## 范围

- [x] 将共享认证骨架改为桌面左侧说明、右侧表单。
- [x] 手机及平板保留窄版单列，保持纸刊组件风格。
- [x] 验证登录、注册与账户恢复页面的布局和交互。

## 非目标

不增加内容、图片、依赖或认证功能；不修改权限、数据和路由；不提交或推送。

## 架构边界

调整 components/layout 纯 UI 骨架，保持公共参数与 Server Component。认证功能及服务端入口不变。

## 验收条件

- [x] 1024px 起采用左右两栏，说明区与表单分隔清楚，输入宽度适宜。
- [x] 390、768、920px 单列，所有验收视口无水平溢出。
- [x] 登录、注册、验证码和密码恢复保持原有行为，键盘顺序有效。

## 发布影响

- 预期版本影响：无需单独发布。
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：共享骨架参数和页面接口保持不变；回滚布局类即可。

## 测试

更新现有浏览器布局验收，查看手机、桌面认证截图；运行认证、首页与密码恢复回归，typecheck、lint 和规范检查。

## 风险 / 回滚

登录、忘记密码和重置密码共用骨架，需要同时检查长注册表单及错误提示，避免双栏挤压输入和操作栏。回滚骨架及相应断言即可。
