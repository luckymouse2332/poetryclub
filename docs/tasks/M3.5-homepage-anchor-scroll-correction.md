# M3.5 首页锚点滚动与交互回退

## 背景

M3.4 对用户意图理解有偏差：加入了正文页面切换动画和较强的诗作行 hover，同时首页同一 hash 的“关于”链接无法可靠重复触发。用户要求恢复简洁列表，移除页面切换动画，并对齐参考示例中刊头与页面锚点的平滑滚动行为。

## 范围

- [x] 移除 React / Next.js View Transition 页面切换动画。
- [x] 恢复最新诗作列表原有的静态样式。
- [x] 让“关于”和刊头“回中诗社”在首页可重复触发平滑锚点滚动。
- [x] 将桌面端首屏文字从左边缘向内移动。
- [x] 更新浏览器测试并复核多视口布局。

## 非目标

- [x] 不改变诗作查询、认证、授权或数据库逻辑。
- [x] 不加入“最新诗作”和“关于”之间的图片。
- [x] 不把首页整体改为 Client Component。

## 架构边界

首页继续使用 Server Component。锚点重复滚动行为放在已有的 `SiteNavLink` Client Component 中，只处理当前路径上的 hash 链接，并保留修饰键、新标签页和跨路由导航的原生行为。减少动态效果偏好下使用即时滚动。

## 验收条件

- [x] 同一页面中多次点击“关于”都能滚动到关于区域。
- [x] 多次点击刊头“回中诗社”都能把首屏顶边滚动到视口顶部，使导航栏离开视口。
- [x] 页面切换不再播放淡出、模糊或位移动画。
- [x] 最新诗作行不再改变背景、阴影或文字颜色。
- [x] 1440 像素视口中大标题左边距明显大于修改前的 32 像素。
- [x] typecheck、lint、Vitest、首页 E2E 和生产构建通过。

## 测试

更新首页 Playwright，覆盖同一 hash 的重复点击、刊头滚动终点、诗作行静态 hover 和响应式首屏位置。运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、首页 E2E 与 `pnpm build`。

验证结果：`pnpm typecheck`、`pnpm lint`、187 项 Vitest、14 项首页 Playwright 和 `pnpm build` 均通过。浏览器复核了 375 与 1440 像素页面；1440 像素下大标题左边距由修改前实测 32 像素增加到约 96 像素。

按项目流程调用了 `deepseek-review` 只读审查；命令在 120 秒后超时，未返回审查文本，也未写入工作区。随后完成聚焦人工审查，未发现阻断级或严重问题。

## 风险 / 回滚

自定义 hash 点击只在目标路径等于当前路径且页面存在目标元素时生效，其余情况继续交给 Next.js Link。回滚时删除 `SiteNavLink` 的同页 hash 处理，并把刊头链接恢复为 `/`。
