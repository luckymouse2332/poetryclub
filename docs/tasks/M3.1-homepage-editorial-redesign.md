# M3.1 首页诗刊化视觉重构

## 背景

现有首页使用通用落地页 Hero、卡片和状态 Badge，和“班级诗刊、私人档案、线上纪念册”的产品气质不一致。本任务依据用户提供的桌面效果图、`docs/mockups/杂诗集封面.jpg`、`docs/mockups/印章图.jpg` 以及 `docs/design-system.md` 重构首页，同时保留既有公开诗作查询和认证行为。`docs/mockups/两页诗稿.jpg` 仅作为实拍资料参考，没有代替书面要求指定的红印章页。

## 范围

- [x] 将顶部区域重构为单标志的诗刊刊头，并保留诗作、关于、登录或账户入口。
- [x] 使用两张独立实拍图组成响应式档案照片拼贴。
- [x] 将最近三篇公开诗作改为目录式纵向索引，复用现有查询与数据字段。
- [x] 将关于诗社、收录标准和开发状态改为克制的编辑式排版。
- [x] 补充首页渲染、公开诗作过滤、链接和移动导航相关测试。
- [x] 在 375、768、1024、1440 像素视口完成视觉与可访问性检查。

## 非目标

- [x] 不修改数据库 schema、migration、认证流程、诗作权限或 API 契约。
- [x] 不新增评论、收藏等尚未完成的业务能力。
- [x] 不引入动画库、图片生成资源或庞大的新设计系统。
- [x] 不修改、合并或发布 `master`、`rc1` 与 release tag。

## 架构边界

首页继续作为 Server Component；页面仅组合视图并调用既有 service。数据库访问保持在 `src/server`，公开诗作筛选继续以既有 `published`、`visible` 和 `publishedAt` 语义为准。静态编辑式结构不套用 Card；交互继续复用现有 Link、Button 与认证导航。用户文本以 React 纯文本渲染，不引入 HTML 渲染。

## 验收条件

- [x] 首页按“刊头 → 简介与阅读入口 → 实拍照片 → 最新诗作 → 关于 → 开发状态与页脚”的顺序响应式呈现。
- [x] 桌面端两张实拍图保留独立边界并轻微错位；移动端改为自然上下排列。
- [x] 最近三篇内容来自既有公开诗作查询，草稿、撤回和隐藏诗作不进入结果。
- [x] 登录或账户入口存在，但不是首屏主操作。
- [x] 首页无大面积 Card、Badge、普通区域阴影和固定窄屏双栏。
- [x] 375 至 1440 像素视口无横向滚动，键盘焦点清楚可见。
- [x] lint、typecheck、Vitest、首页 Playwright 和生产构建通过。

## 测试

按 `package.json` 中实际脚本运行 `pnpm lint`、`pnpm typecheck`、`pnpm test`、与首页相关的 `pnpm test:e2e` 目标和 `pnpm build`。仓库没有格式化脚本时记录这一事实，不臆造命令。视觉验证覆盖 375、768、1024、1440 像素视口，并检查浏览器控制台。

## 风险 / 回滚

主要风险是照片裁切在不同宽度下暴露多余桌面内容、目录长标题破坏布局，以及全局刊头改动影响其他页面。修改集中在首页、站点刊头和必要的样式/测试中；回滚时可逐文件恢复，不涉及数据或 migration。
