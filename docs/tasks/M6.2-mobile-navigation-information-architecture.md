# M6.2 移动端导航信息架构重构

## 背景

当前移动端刊头同时展示品牌、全站导航和账户二级导航，进入账户页面后形成三层纵向导航，占用首屏并混淆“我的”与账户入口的职责。本任务以现有移动端截图为问题基线，参考 Poetry Foundation 的全屏导航信息架构，继续使用回中诗社既有视觉语言。

## 范围

- [x] 将移动端 Header 重构为汉堡菜单、真正居中的站名和账户入口三段式单行结构。
- [x] 使用现有 Dialog 与 DropdownMenu 行为实现全站菜单和账户菜单。
- [x] 复用通知未读数量，在账户首字符圆标和通知菜单项上显示克制状态点。
- [x] 使用 Unicode grapheme 生成单字符账户标记，并提供邮箱回退。
- [x] 将账户二级导航移动到各账户页面标题之后。
- [x] 更新导航文档、单元测试、E2E 与视觉 QA。

## 非目标

- [x] 不修改桌面导航的既有信息架构和视觉样式。
- [x] 不修改认证、通知、权限或登出业务逻辑。
- [x] 不新增头像字段、上传能力、第三方头像服务或数据库 migration。
- [x] 不修改 About 页面内容及其他已完成页面的业务布局。

## 架构边界

会话、权限和通知数据继续由 Server Component 读取，只把显示名称、首字符、管理员状态和未读数量等最小可序列化视图传给交互组件。移动菜单复用 shadcn/ui Dialog，账户菜单复用 DropdownMenu；不新增无头组件实现。账户二级导航继续复用 SecondaryNavigation 与既有路由匹配语义。

## 验收条件

- [x] 320、375、390、430px 下 Header 只有一行，站名几何居中，左右控件点击区域不少于 44px。
- [x] 匿名用户右侧显示“登录”；登录用户显示一个 Unicode grapheme 圆标。
- [x] 全站菜单包含诗作、关于、登录后通知和正常管理员的管理入口，不包含“我的”或账户管理入口。
- [x] 账户菜单包含我的诗作、账户信息、账户安全与登出；有未读通知时圆标显示小暗红点。
- [x] 全站菜单支持 Escape、关闭按钮、菜单项导航、焦点归还和桌面断点自动关闭。
- [x] 移动账户二级导航位于页面标题之后，桌面工作区导航保持不变。

## 发布影响

- 预期版本影响：`MINOR`
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：只涉及导航组件、响应式布局和展示工具，可按组件独立回滚。

## 测试

补充 Unicode grapheme 单元测试；更新匿名、成员、管理员、通知未读、移动菜单键盘与账户二级导航 E2E；运行 `pnpm check:conventions`、`pnpm typecheck`、`pnpm lint`、`pnpm test`、相关 `pnpm test:e2e` 与 `pnpm build`。

## 风险 / 回滚

主要风险是移动 Dialog 与桌面断点切换后的残留锁屏、账户页二级导航重复，以及既有 E2E 对旧导航结构的假设。通过受控 open 状态、媒体查询关闭和多视口回归覆盖；若出现问题，可恢复 SiteHeader 插槽和 WorkspaceShell 的移动导航渲染。
