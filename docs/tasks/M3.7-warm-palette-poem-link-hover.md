# M3.7 暖纸配色与诗名链接反馈

## 背景

当前 Surface 和 Paper 接近白色，与用户提供的示例网站暖米色纸面差异较大；首页诗名链接也缺少独立的可交互提示。用户要求参考示例站配色，并为诗名链接增加 hover 下划线。

## 范围

- [x] 以示例站 `#F1EBDF` 暖纸色为 Page 基准更新全局色板。
- [x] 调整 Surface、Paper、Ink、Seal 和边框色，使整体层次保持克制。
- [x] 同步更新 `docs/design-system.md` 色板表。
- [x] 为首页诗名链接增加 hover 与 focus-visible 下划线。
- [x] 更新浏览器测试并复核移动端与桌面端配色。

## 非目标

- [x] 不恢复诗作整行背景、阴影或整体变色 hover。
- [x] 不加入纸张纹理图片、深色模式或新的视觉组件。
- [x] 不改变首页布局、锚点滚动、查询和认证逻辑。

## 架构边界

具体颜色值只修改 `src/app/globals.css` 的基础色板；页面继续使用语义 Token。诗名链接样式限定在首页 CSS Module，保留全局焦点轮廓。

## 验收条件

- [x] 页面主背景计算色为 `rgb(241, 235, 223)`。
- [x] 标题正文与背景保持 WCAG AA 以上对比度。
- [x] 诗名链接静止时没有可见下划线，hover 和键盘聚焦时出现印章红下划线。
- [x] 诗作整行背景与阴影在 hover 前后保持一致。
- [x] 390、1024、1440 像素视口无横向溢出且纸面层次清楚。
- [x] typecheck、lint、Vitest、首页 E2E 和生产构建通过。

## 测试

更新首页 Playwright，检查页面与 Surface 计算色、诗名链接下划线颜色、focus-visible 状态和诗作行静态样式。运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、首页 E2E 与 `pnpm build`。

验证结果：页面背景计算色为 `rgb(241, 235, 223)`，Surface 为 `rgb(244, 239, 229)`。主要文字与 Page 对比度为 14.02:1，次要文字为 6.21:1，最弱文字调整后为 4.62:1，均达到普通文本 AA。

诗名链接的 hover 与 focus-visible 下划线颜色变化通过浏览器断言，诗作整行的背景和阴影保持不变。`pnpm typecheck`、`pnpm lint`、187 项 Vitest、14 项首页 Playwright 和 `pnpm build` 均通过；截图复核了 390 与 1440 像素视口及单独的诗名 hover 状态。

按项目流程调用了 `deepseek-review` 只读审查；命令在 90 秒后超时，未返回审查文本，也未写入工作区。人工审查发现初版 muted 文本与 Page 对比度为 4.36:1，随后将 Token 加深为 `#70685E`，复测达到 4.62:1，未发现其他阻断级或严重问题。

## 风险 / 回滚

色板为全站语义 Token，登录、账户和管理页面也会同步变暖。回滚时恢复 `globals.css` 和设计系统表中的基础色值；链接样式可独立删除。
