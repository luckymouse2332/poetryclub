# M6.11 深色模式切换

## 背景

用户明确要求增加深色模式切换，替代设计系统此前不提供深色模式的范围限制。延续校园纸刊设计，保持页面与纸面层次，不增加主内容跳转动画。

用户在实现期间否决暖棕深色配色，改用冷静的墨蓝灰：外围 #182029、纸面 #2C3745、正文 #E7EDF3。浅色纸刊色板不变。

## 范围

- [x] 桌面和手机导航提供可访问的主题切换按钮。
- [x] 首次跟随系统，手动选择保存于本机；支持跨标签同步、系统变化与存储受限回退。
- [x] 统一深色语义色板，覆盖内容、表单、状态、浮层、首页锯齿边与错误页。
- [x] 首屏在水合前应用主题，验证深浅模式与现有业务回归，同步文档。

## 非目标

不更改路由、业务、权限、数据库或字体；不新增依赖、上游原语、账户偏好接口或主内容动画。不提交、推送、发布。

## 架构边界

主题工具位于 lib，切换器使用现有 IconButton/Lucide，为项目 UI 组合而非新原语。root layout 仅加载可信的固定初始化脚本与组件，默认服务端页面不变为 Client Components；浏览器偏好不访问服务端或数据库。

## 验收条件

- [x] 320/390/768/920/1024/1440px 导航不溢出，手机品牌居中，操作区域至少 44px。
- [x] 系统默认、显式覆盖、刷新和路由保留、标签同步及存储异常正确；首屏主题在客户端水合前生效，无水合错误。
- [x] 内容纸面区别于外围，正文/辅助文字/状态可读，输入和焦点边界清楚，浮层与真实照片自然。
- [x] 仅保留导航动画，深浅切换不增加页面淡入或位移；减少动态效果有效。
- [x] 规范、类型、lint、单元、E2E 与生产构建通过。

## 发布影响

- 预期版本影响：无需单独发布（若后续打包发布，属于新增用户功能）。
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：存储受限仍可切换当前页面；移除切换器、初始化脚本与深色色板即可回滚，浅色基线不变。

## 测试

单元验证偏好解析和初始化脚本的系统/持久化/异常分支。浏览器检查主题控制、跨标签、首屏、键盘、减少动画、实际颜色/对比度、组件与页面截图和断点。执行 check:conventions、typecheck、lint、test、test:e2e、build。

验证结果（2026-10-04）：

- check:conventions、typecheck、lint、283 项单元测试、最终全量 129 项 E2E（单次 9.2 分钟）及生产构建通过。
- 12 项主题专项覆盖六种宽度、系统默认/显式覆盖、刷新、跨标签、存储异常、键盘与减少动画；阻断 Next 客户端脚本时，head 初始化仍在水合前应用保存的深色主题。
- 深色组件检查覆盖全部 22 个基础组件及输入/焦点/错误/禁用、Dialog/Dropdown/Popover 的真实计算样式与对比度；深色阅读、评论、认证、编辑器、通知、后台截图保存在 output/playwright/dark-mode，并复核主要页面。
- 首屏脚本只在初始服务端 HTML 输出，水合后移除，避免权限变化和客户端路由插入不可执行 script 的警告。测试截图保留 caret 初始样式，避免截图工具在水合前注入隐藏 caret 的样式。
- 全量回归发现既有锚点检查把首页 #top 误认为文档 scrollY=0；改为验证实际目标贴合视口顶端，保留原有应用锚点行为，最终导航用例全部通过。
- 本地生产预览验证深色首屏、切换后保存、/poems、/collections、/login 的 200 与 /ui-preview 的 404，无水合错误。使用 next start 检查生产构建，未验证 standalone 启动入口；临时 3011 服务已关闭，原 3000 开发服务未停止。
- 日志位于 output/m6-11-*.log，生产截图为 output/playwright/dark-mode/production-home.png。构建仅使用临时邮件校验值，未发送邮件；无依赖或数据库改动，保留 960585c，未提交、推送或发布。

## 风险 / 回滚

水合、闪烁与移动导航拥挤是主要风险；使用固定 head 初始化脚本、html 局部水合属性容忍及共享主题订阅，手机左右区域对称。所有颜色通过语义 Token 切换，不逐组件叠加 dark 类。照片保持原始内容。
