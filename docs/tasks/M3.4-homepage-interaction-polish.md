# M3.4 首页正文与交互细节优化

## 背景

M3.3 已完成首页首屏构图。用户随后提供一份 React 静态示例，要求继续参考其中的正文边距、链接反馈、页面跳转过渡和最新诗作 hover 效果，但明确不加入示例中位于“最新诗作”和“关于”之间的图片。本任务依据示例源码、现有设计系统和 Next.js 16.2 本地 View Transitions 文档完成细节收敛。

## 范围

- [x] 调整首页正文区域的响应式左右边距，让宽屏内容更充分使用视口。
- [x] 为最新诗作整行增加 hover 与 `focus-within` 反馈。
- [x] 为首页文字链接增加克制的箭头位移动效。
- [x] 使用 Next.js 16 官方 View Transition 支持，为站内页面跳转增加短促过渡。
- [x] 更新交互测试并完成多视口浏览器检查。

## 非目标

- [x] 不加入示例中“最新诗作”和“关于”之间的图片。
- [x] 不修改诗作查询、数据库、认证、授权或 Server Action。
- [x] 不引入动画库，不把页面业务逻辑迁移到 Client Component。

## 架构边界

首页仍为 Server Component。页面过渡使用 Next.js 16.2 文档提供的 `experimental.viewTransition` 与 React `ViewTransition`，只包裹根布局中的 `<main>`；刊头、页脚、会话读取和业务数据保持原有边界。动画必须遵守 `prefers-reduced-motion`。

## 验收条件

- [x] 首页正文在移动端保留至少 16px 边距，在桌面端使用接近示例的约 2.55vw 单侧边距。
- [x] 诗作行在鼠标 hover 和键盘聚焦时同时出现非颜色单一的可见反馈。
- [x] 首页文字链接 hover 时箭头平滑右移，焦点样式仍然清楚。
- [x] 站内路由跳转时只有正文区域进行短促过渡，刊头和页脚不随内容移动。
- [x] 减少动态效果偏好下关闭 View Transition 动画。
- [x] typecheck、lint、Vitest、首页 E2E 和生产构建通过。

## 测试

更新首页 Playwright，检查诗作行 hover/focus 样式、页面过渡 CSS 和站内导航结果。运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、首页 E2E 与 `pnpm build`，并复核 375、768、1024、1440 像素视口。

验证结果：`pnpm typecheck`、`pnpm lint`、187 项 Vitest、14 项首页 Playwright 和 `pnpm build` 均通过。浏览器截图覆盖 375、768、1024、1440 像素视口，并单独检查了最新诗作行的 hover 状态。

按项目流程调用了 `deepseek-review` 只读审查；命令在 180 秒后超时，未返回审查文本，也未写入工作区。随后完成了人工聚焦审查，并补强键盘焦点测试，使其先移开鼠标再验证 `focus-within`，未发现阻断级或严重问题。

## 风险 / 回滚

View Transition 在 Next.js 16.2 中仍为实验特性；不支持该 API 的浏览器会正常跳转但不播放动画。回滚时移除根布局包装、实验配置和对应 CSS 即可，页面功能不会受影响。
