# BUG-7 工作区中等视口溢出修复

## 背景

成员工作区在 `1024px` 宽视口已经启用桌面常驻侧栏，同时“我的诗作”也切换为五列管理表格。侧栏、页边距和间距占用后，主内容宽度不足以容纳表格，导致操作列被推出视口。

## 范围

- [x] 调整工作区常驻侧栏的响应式断点。
- [x] 调整“我的诗作”五列管理布局的响应式断点。
- [x] 补充 `1024px` 与 `1280px` 的响应式回归测试和视觉核对。

## 非目标

- [x] 不修改账户、诗作或管理后台业务行为。
- [x] 不改动 About 页面及其未提交内容。

## 架构边界

只调整现有布局组件和诗作展示组件的响应式样式，复用既有设计 Token、导航组件与操作组件，不改变 Server Component 边界、路由、数据结构和权限逻辑。

## 验收条件

- [x] `1024px` 视口使用顶部账户导航和纵向诗作条目，页面无横向溢出，操作完整可见。
- [x] `1280px` 及以上视口恢复常驻侧栏和五列管理布局，内容无裁切。
- [x] 手机端既有单列布局不回退。

## 发布影响

- 预期版本影响：`PATCH`
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：仅 CSS 响应式断点变化，可按组件回滚。

## 测试

新增 Playwright 响应式断言，并运行 `pnpm typecheck`、`pnpm lint`、相关 E2E、`pnpm test` 与 `pnpm build`。

## 风险 / 回滚

共享工作区侧栏在 `1024–1279px` 改为顶部导航，可能影响成员和管理页面的导航形态；通过关键断点视觉检查覆盖。若出现回归，可独立恢复 `WorkspaceShell` 的原断点。
