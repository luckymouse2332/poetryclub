# M6.8：纸刊界面一致性与留白收尾

## 背景

M6.7 已建立校园纸本诗刊基线，但用户指出评论背景与正文贴边等细节仍像半成品。完整扫描项目文件，统一颜色、背景承载与间距，使公开阅读、成员操作和管理界面形成连续的设计语言。

## 范围

- [x] 扫描全部前端 TSX/CSS 文件及页面组合，登记问题与处理范围。
- [x] 修复评论、回复、提示、列表和表单中背景与内边距不匹配、层级不一致的问题。
- [x] 统一纸面颜色、章节留白、标题字体及列表分隔规则。
- [x] 检查五个响应式尺寸、长文本与实际业务回归，同步设计系统。

## 非目标

不更换纸刊方向、不增加功能或依赖，不修改权限、分页、数据库和业务流程；保留省略号、锯齿页边、无上下空白的首页首屏、认证左右布局。保持当前分支、不提交、不推送、不发布。

## 架构边界

页面组合留在 app，业务 UI 留在 features，纯 UI 在 components；沿用 shadcn/Radix 原语及公共接口、焦点管理和 data-slot。服务端文件扫描用于确认边界，不改业务规则。

## 验收条件

- [x] 所有有背景的内容表面具备明确内边距；连续目录行使用透明底，不出现零边距浅色块。
- [x] 页面背景与阅读/表单纸面有稳定关系，标题、分隔和操作层级一致。
- [x] 评论及一级回复在小屏保留可用宽度，焦点高亮不让正文贴边。
- [x] 390、768、920、1024、1440px 布局无横向溢出，已有交互与权限断言通过。
- [x] 规范检查、类型检查、lint、单元测试、全量 E2E 范围及失败项复跑、生产构建通过；人工检查代表页面截图。

## 发布影响

- 预期版本影响：无需单独发布。
- migration / 环境变量 / 部署顺序：无。
- 兼容性与回滚边界：仅 UI 样式、组合与验收；保留原提交 960585c。
