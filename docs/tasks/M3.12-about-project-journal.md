# M3.12 关于回中诗社页面

首页已经建立暖纸色、旧诗集与班级档案式的视觉基线，但站点缺少一个独立页面说明诗社来源、网站技术演进、当前架构与维护记录。本任务新增 `/about`，并在后续修订中补充历史源码、个人项目经历和主要版本里程碑。

## 架构边界

`src/app/about/page.tsx` 只负责路由与 metadata，页面内容归入 `src/features/about`。页面保持默认 Server Component，不访问数据库，不新增服务端写入口。视觉实现使用现有语义 Token、衬线字体和原生语义结构，不新建通用 UI 组件。历史仓库链接使用普通外部链接和安全 `rel` 属性；技术描述以公开源码、正式任务记录和用户明确补充为依据。

## 风险 / 回滚

主要风险是新增长页面在窄屏出现时间轴挤压，或导航改动与当前首页重构产生冲突。样式限定在 about feature 的 CSS Module 中；回滚时删除 about 路由与 feature 文件，并恢复导航链接即可，不涉及数据迁移。
