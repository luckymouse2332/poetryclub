# M3.11 首页全幅实拍图参考稿改造

## 背景

现有首页仍采用左侧纸面与右侧照片叠合、带不规则裁切边缘的结构，且站点名称和年级信息在导航与首屏之间分散。用户提供新的诗集实拍图和目标参考稿，要求在保留公开诗作查询、认证导航、登出与管理员权限判断的前提下，将首页调整为低矮刊头、全幅照片首屏和下方双栏目录式信息区。

## 范围

- [x] 将用户提供的图一保存为项目本地首页资源，并以 `next/image` 全幅铺满首屏。
- [x] 重排站点导航，在品牌区同时显示“回中诗社”和“2021—2024级”，保留现有认证与权限分支。
- [x] 删除首页不规则多边形分割，改为水平米白遮罩、主文案和文字链接。
- [x] 使用现有公开诗作服务展示最近三篇可见已发布诗作，并按参考稿重排最新诗作与关于信息。
- [x] 更新主题 Token、设计系统说明和首页 E2E 断言，完成响应式检查。

## 非目标

- [x] 不修改诗作发布、撤回、审核、登录、会话、账户或管理员权限规则。
- [x] 不修改数据库 schema、migration 或公开诗作查询契约。
- [x] 不新增 UI 库、远程图片、装饰图标、动画库或首页 Client Component 业务逻辑。

## 架构边界

首页继续作为 Server Component，只组合 `listRecentPublishedPoems(3)` 返回的公开数据和静态内容。数据库访问仍位于 `src/server/services`，认证导航仍由服务端 `AuthNavigation` 读取最小会话视图，管理员入口继续依赖 active admin 判断。首页图片使用本地静态导入和 Next.js Image；颜色由全局语义 Token 管理，页面局部布局由 CSS Module 管理。

## 验收条件

- [x] 桌面端导航为暖米白低矮横向布局，品牌区显示名称与年级，游客和登录用户入口保持现有权限逻辑。
- [x] 首屏使用图一完整横幅背景，桌面高度约为视口的 60% 至 70% 且至少 520px，无锯齿或多边形边缘。
- [x] 首屏只显示指定文案、暗红短线和指向 `/poems` 的“随便翻翻”链接。
- [x] 下方按约 35% / 65% 双栏展示最近三篇公开诗作与指定关于文案，窄屏改为最新诗作在前的单栏。
- [x] 空状态、长标题、作者显示、键盘焦点和 375 至 1440 像素无横向滚动得到验证。
- [x] `pnpm typecheck`、`pnpm lint`、`pnpm test`、相关首页 E2E 与 `pnpm build` 通过。

## 风险 / 回滚

主要风险是宽幅图片在窄屏裁切后主体位置不佳、遮罩对比度不足，以及登录后较多导航项在中等宽度换行。改动集中在首页、站点刊头、语义色 Token、设计说明、测试和新增本地图片；回滚时恢复这些展示文件并移除新增资源，不涉及数据迁移。
